## The Role

A four-month co-op placement at Imagine Communications, a company that builds software for the broadcast and media industry. My work sat at the intersection of front-end engineering and algorithmic problem-solving.

## Channel Scheduling UI

Built front-end features for a channel scheduling application using **TypeScript and AngularJS** — an early exposure to typed JavaScript at a time when TypeScript was still gaining traction in the industry. Implemented a **drag-and-drop interface for a channel editor**, which required careful state management to keep the UI consistent as users rearranged items.

## Packing Algorithm

The more interesting problem: designed an algorithm to **cost-effectively fit broadcast channels to a server**, a variant of the bin-packing problem. Given a set of channels with different resource requirements and a set of servers with fixed capacity, find an allocation that minimises cost. This was my first experience translating a real business constraint into a formal algorithmic problem — the process of abstracting the domain details away until you can see the structure underneath.

## First Engineering Role

This was my first professional engineering experience. The things that stuck: the importance of understanding the problem before writing code, how much you learn from reading other people's code, and that a small well-scoped feature shipped is worth more than a large ambitious one in progress.
